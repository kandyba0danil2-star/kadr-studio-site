# KADR Studio — website

Static marketing site for KADR Studio, a Windows video constructor (one sentence or a long brief → a finished video with script, pictures on your own NVIDIA card, live AI scenes, voice, music and subtitles). Plain HTML + CSS + a few lines of vanilla JS, no build step and no trackers: `index.html` is the Russian page, `en/index.html` the English one, shared styles and script live in `assets/`, and every image and video in `media/` was cut from videos made in KADR Studio itself. Preview locally with `python -m http.server` and open http://localhost:8000; publish as-is to any static host (GitHub Pages ready, `.nojekyll` included). Before publishing, replace the contact placeholder (search for `PLACEHOLDER`) and make the Open Graph image URLs absolute once the domain is known.
